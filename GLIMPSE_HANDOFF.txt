WORKFLOW
----------------------------------------------------------------
This project is built collaboratively between Claude (claude.ai)
and Claude Code (CC) running in the terminal. The workflow is:

- Claude (claude.ai chat) acts as creative director and technical
  translator. The human gives feedback and direction in plain
  language. Claude interprets it and writes precise prompts for CC.

- Claude Code (terminal) executes all file edits directly.
  It reads and writes index.html, style.css, and main.js.

- The human never writes code directly. They describe what they
  want, Claude drafts the CC prompt, human pastes it into CC.

- Screenshots are shared in the Claude chat when visual feedback
  is needed. Claude reads them and adjusts the next CC prompt.

- The Claude chat is for strategy, feedback, and prompt generation
  only. CC is for execution.

CURRENT CARD SIZING RULES (style.css — exact values)
----------------------------------------------------------------

Base card rule:

  .proj-card {
    position: relative;
    cursor: none;
    margin-bottom: 50px;
  }

Base odd/even pattern:

  .proj-card:nth-child(odd) {
    flex-basis: 50%;
    height: 340px;
  }
  .proj-card:nth-child(even) {
    flex-basis: 32%;
    height: 460px;
    margin-top: 160px;
    margin-left: 160px;
  }

Row-2 margin overrides:

  .proj-card:nth-child(4n+4) {
    margin-top: 160px;
  }
  .proj-card:nth-child(4n+3) {
    margin-top: 0;
  }

Explicit per-card overrides — order-independent ([data-index="N"]):

  /* Wild Ice — data-index="1". Inherits odd's flex-basis: 50%, overrides
     height, resets margins so first card sits flush. */
  .proj-card[data-index="1"] {
    height: 338px;
    margin-top: 0;
    margin-left: 0;
  }

  /* The Process / Jasmine — data-index="2". Matches even pattern
     explicitly + adds bottom margin (decoupled from DOM position). */
  .proj-card[data-index="2"] {
    flex-basis: 32%;
    height: 460px;
    margin-top: 160px;
    margin-left: 160px;
    margin-bottom: 50px;
  }

  /* Shu — data-index="5". Inherits odd's flex-basis: 50%, overrides
     height to a shorter panoramic ratio. */
  .proj-card[data-index="5"] {
    height: 252px;
  }

  /* Austin Farwell — data-index="8". Anchor still + hover video to
     center bottom so framing matches between still and loop. */
  .proj-card[data-index="8"] .proj-thumb img,
  .proj-card[data-index="8"] .proj-video {
    object-position: center bottom;
  }

  /* Elladj Baldé — data-index="9". Cap card width and re-center crop
     (this card is wider than the others). */
  .proj-card[data-index="9"] {
    max-width: 720px;
  }
  .proj-card[data-index="9"] .proj-thumb img,
  .proj-card[data-index="9"] .proj-video {
    object-position: center center;
  }
