WORKFLOW
----------------------------------------------------------------
This project is built collaboratively between Claude (claude.ai)
and Claude Code (CC) running in the terminal. The workflow is:

- Claude (claude.ai chat) acts as creative director and technical
  translator. The human gives feedback and direction in plain
  language. Claude interprets it and writes precise prompts for CC.

- Claude Code (terminal) executes all file edits directly.
  It reads and writes index.html, style.css, and main.js.

- The human never writes code directly. They describe what they
  want, Claude drafts the CC prompt, human pastes it into CC.

- Screenshots are shared in the Claude chat when visual feedback
  is needed. Claude reads them and adjusts the next CC prompt.

- The Claude chat is for strategy, feedback, and prompt generation
  only. CC is for execution.

----------------------------------------------------------------
WHAT IS BUILT
----------------------------------------------------------------

HERO
- Fixed position, centered in viewport
- Headline: "HUMAN AMBITION IN MOTION."
  Montserrat 800, black, uppercase, centered
- Subhead: "Exploring the 'why' behind our subjects' pursuits."
  Open Sans, ~20px, weight 500, centered
- Fades out and translates up as user scrolls
  Starts fading immediately, fully gone by 50% of viewport height
- #hero-text opacity and transform driven by scroll listener in main.js

NAVIGATION
- Fixed top — logo left, menu items right
- Menu items stacked vertically, right-aligned
- Font: Open Sans, 16px, weight 600, uppercase, letter-spacing .14em
- Hover: letter-spacing expands to .64em, anchored right
  (transform-origin: right center)
- No underline on hover
- Items: WORK, INFO (Contact removed)

PROJECTS SECTION
- z-index: 3, background: transparent
  Hero text visible through gaps between cards
- margin-top: 75vh so first card peeks above fold on load
- padding-left: 80px to give room for vertical labels
- Layout: display flex, flex-wrap wrap, justify-content space-between
  This matches Mike Carson's grid system exactly
- Card sizing:
    Odd cards:   flex-basis 50%,  height 340px
    Even cards:  flex-basis 32%,  height 460px,
                 margin-top 200px, margin-left 200px
    4n+4 cards:  margin-top 200px
    4n+3 cards:  margin-top 0
- margin-bottom: 360px between cards for generous negative space
- Each card has a .proj-label — vertical text using
  writing-mode: vertical-rl, transform: scale(-1,-1),
  positioned left: -55px

CARDS
- .proj-thumb: overflow hidden, width 100%, height 100%
- .proj-thumb-inner: position absolute, inset 0
- Placeholder boxes: darker fill, image icon + label
- Card 1 (Elladj): placeholder
- Card 2 (Momo): real image — /assets/MomoTest.png
- Cards 3–6: placeholders
- Hover: image scales 1.05, dark overlay fades in, "View" appears
- .proj-meta: project name + index number below card

GRAIN
- #grain fixed overlay, z-index 2, opacity 0.06
- Animated SVG turbulence noise, shifts every 0.08s
- body::after second grain layer, opacity 0.035, offset phase

CANVAS BG
- #scrub-canvas fixed, z-index 0, opacity 0.22
- Animated ambient light pools that drift slowly
- Scroll position fed into animation phase (simulates video scrub)
- REPLACE with real <video> element when footage is ready

CUSTOM CURSOR
- Small dot, blooms to open ring on hover over interactive elements

ABOUT / FOOTER
- About section has solid background: var(--bg)
  Covers hero as user scrolls past cards
- Contact links: Email, Instagram
